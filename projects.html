01 / MATHEMATICAL MODELLING

Watching glass
change, one layer at a time.

My MSc research explored mathematical models of glass etching. The interesting part is how local surface changes become a changing depth profile. The equations do the bookkeeping. The picture helps you see why.

THE SURFACE LABConceptual demo

Move the sliders: uneven removal creates an uneven surface. This illustration is not the MATLAB solver or a calibrated prediction.

The question

How can a small set of differential equations describe the changing composition of a surface and its removal over time?

The actual implementation

The public release contains two- and three-species MATLAB models using ode45, with surface-fraction and depth-profile plots. An exploratory Python lattice notebook takes a different, discrete view.

Species & rates↓Differential equations↓Surface fractions + depth
Go a little deeper

An ODE solver advances a system state through time using its rates of change. Surface fractions describe the share associated with each species; depth describes removal. Changing rates changes the trajectory. The graphic here only illustrates removal; it does not reproduce those equations.

The useful lesson

A plausible animation is not validation. These models explore selected parameters and are not experimentally calibrated industrial models. The Python notebook also has a known timing-rule issue that can miss events in newly exposed layers.

02 / AUDIO + DEEP LEARNING

A voice is a signal.
An emotion is an inference.

Speech emotion recognition asks a model to find patterns in audio that relate to labelled emotions. My project explored wavelet and MFCC features with recurrent and convolutional models, plus a microphone interface.

AUDIO WAVEFORMSynthetic illustration

Click the stages above. Graphics use synthetic data; this page does not run the trained model or listen to your microphone.

STAGE 01

Start with the sound.

What are MFCCs and wavelets?

MFCCs summarise the short-time spectral shape of speech on a perceptually motivated frequency scale. A discrete wavelet transform separates a signal into components at different scales. Both offer representations a model can learn from; neither directly measures an emotion.

What I explored

TESS, CREMA-D, RAVDESS and SAVEE; eight emotion classes; DWT and MFCC feature settings; LSTM and CNN–LSTM model families. A Tkinter interface connected microphone capture to classification.

Read the score with its context

The project reported a best CNN–LSTM accuracy of 99.64% on TESS. That is a dataset-specific result, not evidence of equivalent performance on unseen speakers, accents or noisy recordings. Split design and speaker overlap matter.

03 / COMPUTER VISION + EDGE SYSTEMS

Pixels in.
Useful coordinates out.

The edge computer-vision prototype connects object detection to messaging and safe alerts. Finding an object is only the first step: the rest of the system needs a small, usable description of where it is.

DETECTION → MESSAGESchematic demo
A synthetic box and fixed example score explain the data flow. This is not live detection, hardware control or a measured model output.
A system, not just a bounding box
Camera frames enter YOLOv5. The detection code extracts bounding-box centres and sends coordinates through MQTT. A receiver can then log an alert or use the optional GPIO / Arduino integration.
Camera / video↓YOLOv5 → box centre↓MQTT → receiver → alert
Why compute the centre?
For a box with corners (x₁, y₁) and (x₂, y₂), the centre is ((x₁ + x₂) / 2, (y₁ + y₂) / 2). It condenses the location into two values that another component can consume. A centre point alone is not a persistent tracking identity.
Why does the threshold matter?
A higher threshold filters out lower-confidence detections, but can also suppress useful detections. In this demo, the example score stays at 0.82: moving the threshold above it hides the box and suppresses the illustrative message.
The engineering lesson
A working detector still needs a camera source, trained weights, a reachable broker and a receiver that understands its messages. The public repository is a demonstration-oriented prototype; hardware and network settings need configuration.
